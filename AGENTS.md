# Project Overview

Angular 21 single-page application for anime and game of the year reviews.
Firebase (Firestore + Hosting) backend. Tailwind CSS + Angular Material UI.

## Tech Stack

- Angular 21 (standalone components, signals)
- Firebase / Firestore
- Angular Material
- Tailwind CSS
- Vitest

## Key Directories

```
src/app/
  core/          — auth, shared services, utilities
  features/      — feature modules (anime, games, of-the-year)
  shared/        — reusable components and utilities
.bob/rules/      — Bob workspace rules (always loaded)
```
